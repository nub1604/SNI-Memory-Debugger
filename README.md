# SNI Memory Debugger

A cross-platform desktop tool for watching and editing SNES memory in real time, built with Avalonia and SNI's gRPC interface. Load a WLA-DX `.sym` file, search for labels, and stream live values from a connected FX Pak Pro (or other SNI-supported device) — with the ability to write new values back on the fly.

**Built with:** .NET 8, Avalonia UI, [SNI](https://github.com/alttpo/sni)
**Platforms:** Windows, Linux, macOS
